# Overview

This project is based around a simulated small business network. I have not had any opportunities to explore how networks function yet, and I feel this has definitely helped me grasp the many terms and technologies I commonly hear about.

Here are some of the goals I wanted to reach with this project:
- Gain a foundational understanding of the IP protocol suite
- Create and implement separate VLANs with VLAN routing and isolation.
- Understand how to allow room for expansion as the business grows

This project will be separated into multiple documents going over different details:
- [Network Topology](Topology.md)
- [Configuration](Configuration.md)
- [Testing](Testing.md)
- [Security](Security.md)

I modeled and simulated this network in Cisco Packet Tracer, and the associated .pkt file is [SmallBusinessNetwork.pkt](SmallBusinessNetwork.pkt)
